Need a template? Download CSV Template

Upload a CSV file to import or update choices. The CSV file must contain the following columns (matching the export format):

  • model (required) - The model name (e.g., "activity.event", "activity.eventtype")
  • field (required) - The field name
  • value (required) - The choice value (unique key)
  • display (optional) - The display text (defaults to value if not provided)
  • icon (optional) - The icon identifier
  • ordernum (optional) - The sort order number
  • is_active (optional) - Whether the choice is active (true/false, defaults to true). Set to false to disable a choice instead of deleting it.

Note: The sub_choice_of field is available in exports but not yet supported for import.

Valid model choices:

  • activity.event
  • activity.eventtype
  • accounts.user.User
  • mapping.TileLayer
  • observations.region
  • observations.Source

Example CSV format:

model,field,value,display,icon,ordernum,is_active
activity.event,priority,high,High Priority,,1,true
activity.event,priority,medium,Medium Priority,,2,true
activity.event,priority,low,Low Priority,,3,false

Important notes:

  • If a choice with the same model, field, and value already exists, it will be updated
  • To disable a choice (recommended), set is_active=false. This preserves the choice for historical data while hiding it from new selections
  • All rows are validated before any import occurs
  • If any validation errors are found, no data will be imported
  • Errors will be reported by row number
