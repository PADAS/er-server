# ERA-11874 Do not send alerts to alertrules when the owner user is inactive

## Coding task
If the owner of an alert rule is no longer an active user, that rule should be ignored and never processed for EarthRanger alerts. Any inactive-user-linked alert rules should be filtered out of API results.
When a user is being deleted, or marked as inactive through the admin, we need to warn the administrator if the user has alerts configured.
