- ALMOST COMPLETE: provisioned cloud resources to Terraform

## Templating

As templating responsibilities are migrated from vCloud to Terraform, template files will become symlink pointers to rendered (and untracked) files generated by Terraform. 

```
ls -la
ls -la deployment/components/deployments/
api-deployment.yaml -> ../../../templated-deployment/rendered/api-deployment.yaml
...
```

Files are rendered to `templated-deployment/rendered`. It is important to only store ephemeral, rendered files to this directory, since Terraform will delete any extraneous files found in this path.

### Applying overrides for different environments

To override template param defaults for a given feature branch, then create a file called `BRANCH_NAME.tfvars` and store it in the `tfvars-overrides` directory.
